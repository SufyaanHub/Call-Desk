Call Desk

Connect your Android phone with Visual Studio Code.

Call Desk detects cellular call events on your Android phone and synchronizes them with Visual Studio Code.

Download Android App Install VS Code Extension

Call Desk monitors call activity. It does not answer, reject, or record calls.

How it works

  1. 1

    Install Call Desk on Android

  2. 2

    Install Call Desk in VS Code

  3. 3

    Open the extension and generate the pairing QR

  4. 4

    Scan the QR code from the Android app

  5. 5

    Keep the phone connected in the background
