Features

Everything you need to stay connected.

Call Desk keeps phone call activity visible in the editor without changing how you place or manage calls.

01

Real-time Call Detection

Detect incoming, active, missed, and completed cellular calls.

02

VS Code Integration

See call activity directly inside Visual Studio Code.

03

Background Connection

The Android app continues communicating in the background after the UI is closed.

04

QR Pairing

Pair the Android phone with VS Code quickly using QR pairing.

05

Connection Status

See whether the phone is connected, reconnecting, or disconnected.

06

Recent Call Activity

View recent in-memory call activity directly inside VS Code.
